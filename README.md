## 🛠️ Quick Start

### Installation
```bash
# Clone the repository
git clone https://github.com/antono4/awesome-llm-apps.git
cd awesome-llm-apps

# Explore the projects
ls -la projects/
```

### Using RAG Apps
```python
from rag_app import DocumentQA

# Initialize the app
qa = DocumentQA(vector_store="chroma")

# Add documents
qa.add_documents("./docs")

# Query
answer = qa.ask("What is this about?")
print(answer)
```
